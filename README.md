# Cyber Blaster: DX Edition

A neon-styled browser shooter built with HTML, CSS, and vanilla JavaScript.

## Play locally

Open `index.html` in a browser, or run a local static server:

```bash
cd C:\Users\natha\Documents\cyber-blaster-hackclub
python -m http.server 8000
```

Then visit:

`http://localhost:8000/`

## Controls

- Move: WASD or Arrow keys
- Shoot: Left click
- Dash: Spacebar

## Objective

Defend yourself against incoming drones, survive increasing waves, collect powerups, and aim for a high score.
